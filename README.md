# V Service — Едностраничен сайт

Малък едностраничен сайт за сервиз за компютри. Създадени файлове:

- `index.html` — основна страница
- `styles.css` — стилове и анимации
- `script.js` — поведение на изскачащото меню

Как да използвате
1. Поставете вашето лого в същата папка и го кръстете `logo.png`.
2. Отворете `index.html` в браузър (два клика или чрез локален сървър).

Бележки
- Ако `logo.png` не е намерен, страницата показва бяла SVG алтернатива.
- Логото е в тъмен панел, за да се вижда добре бялото сияние.

За бърз преглед (Windows):
```
start index.html
```
Или използвайте прост Python сървър:
```
python -m http.server 8000
# след това отворете http://localhost:8000
```
